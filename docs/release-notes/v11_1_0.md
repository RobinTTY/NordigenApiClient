## New Features

The [`Institution`](/docs/api-reference/responses/institution) class now exposes two additional fields returned by the GoCardless API:

- `MaxAccessValidForDays` (`max_access_valid_for_days`): The maximum number of days an end user agreement with this institution can give access to the account, i.e. the highest value allowed for `accessValidForDays` when creating an agreement.
- `MaxAccessValidForDaysReconfirmation` (`max_access_valid_for_days_reconfirmation`): The maximum number of days of access when the agreement supports reconfirmation. Only provided for institutions that support consent reconfirmation, otherwise `null`.

These fields make it possible to create an end user agreement with the longest access period an institution allows, instead of having to guess it.

:::note
The `Institution` constructor now takes two additional parameters, `maxAccessValidForDays` and `maxAccessValidForDaysReconfirmation`. This only affects you if you construct `Institution` instances yourself (e.g. in tests).
:::
